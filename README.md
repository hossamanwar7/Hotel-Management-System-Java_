# 🏨 Hotel Management System 
 
A desktop-based Hotel Management System developed using Java and Java Swing. 
 
The system provides a simple graphical interface for managing customers, rooms, reservations, payments, and hotel reports. 
 
--- 
 
## 📌 Features 
 
### 👤 Customer Management 
- Add new customers 
- Search customers by ID 
- Delete customers 
- Display all customers 
- Validate customer information 
 
### 🛏️ Room Management 
- Add rooms 
- Search rooms by room number 
- Delete rooms 
- Manage room types 
- Manage room status 
- Track room prices 
 
### 📅 Reservation Management 
- Create reservations 
- Cancel reservations 
- Calculate number of nights 
- Calculate total reservation price 
- Connect customers with rooms 
 
### 💳 Payment Management 
- Add payments 
- Search payments by ID 
- Delete payments 
- Track payment status 
- Support different payment methods 
- Calculate total revenue 
 
### 📊 Reports 
- Total customers 
- Total rooms 
- Available rooms 
- Total reservations 
- Total payments 
- Total revenue 
- Customer list 
 
### ⚙️ Settings 
- Font size settings 
- Notification settings 
- Reset settings 
 
--- 
 
## 🛠️ Technologies Used
